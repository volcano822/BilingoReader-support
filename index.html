技术支持

如何导入文章？

在 App 中点击“导入文章”，粘贴公开的 HTTPS 英文网页地址。受登录、付费墙或网站反爬限制的页面可能无法提取。

为什么翻译暂时不可用？

快速翻译依赖设备端语言资源；精译需要用户自行配置兼容的 AI 服务。请检查网络、语言包和服务商密钥。

如何添加生词？

在英文段落中长按单词，查看音标、系统发音和中文释义，再选择加入生词本。

如何删除本地数据？

文章和生词保存在设备本地。可在 App 内删除对应内容；卸载 App 会删除该 App 的本地数据。

需要帮助时，请在 App Store 的 Bilingo Reader 页面使用“App 支持”入口访问本页，并在反馈中附上 iOS 版本、问题步骤和必要截图。请勿提交 API Key 等敏感信息。

隐私政策

生效日期：2026 年 9 月 26 日

1. 我们处理的数据

Bilingo Reader 以本地优先方式运行。文章、阅读进度、生词、笔记、显示设置与用户配置的 API Key 主要保存在用户设备上。开发者不运营用于集中收集这些内容的业务服务器。

2. 网络请求与第三方服务

当用户导入文章时，App 会访问用户提供的公开网页及网页中的图片资源。当用户使用系统翻译、在线词典、发音或自行配置的 AI 精译功能时，必要的单词、文章片段或提示内容可能被发送至 Apple 或用户选择的第三方服务商。第三方服务的数据处理受其各自条款和隐私政策约束。

3. API Key

用户输入的第三方服务 API Key 保存在设备钥匙串中，用于向相应服务商发起请求。请勿在共享设备上保存不希望他人使用的密钥。

4. 数据共享与出售

开发者不出售用户个人信息，也不将本地阅读数据用于广告画像。App 不包含第三方广告 SDK。

5. 数据保留与删除

本地数据由用户控制，可通过 App 内删除功能或卸载 App 清除。第三方服务可能按其政策保留请求数据，用户应直接查阅并管理对应服务账户。

6. 儿童隐私

本 App 面向一般英语学习者，不专门面向 13 岁以下儿童。监护人应根据实际情况监督儿童使用外部网页和第三方 AI 服务。

7. 安全与变更

我们采用系统钥匙串和本地存储能力保护数据，但任何网络传输都无法保证绝对安全。本政策发生实质变化时，将在本页面更新生效日期。

8. 联系方式

如需提出隐私请求或反馈，请通过 App Store 产品页的开发者支持入口联系我们，并说明请求主题。请勿发送 API Key、密码或其他敏感凭证。
